# Modelo fuente 3D

Coloca aquí el GLB canónico sin optimizar con el nombre:

`mansion.glb`

El build ejecutará `scripts/optimize-models.mjs` y generará temporalmente:

- `public/models/mansion.glb`
- `public/3d-manifest.json`

Si no hay GLB fuente, la experiencia cinematográfica sigue funcionando y el visor Three.js queda desactivado.
